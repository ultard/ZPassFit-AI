# ZPassFit AI Service

Сервис искусственного интеллекта для системы ZPassFit. Используется для анализа данных фитнес-центра, прогнозирования и других задач машинного обучения.

## Технологии

-   **Python 3.14+**
-   **uv** — менеджер пакетов и окружений
-   **gRPC** — для взаимодействия с бэкендом
-   **Библиотеки ML**: CatBoost, LightGBM, XGBoost, Scikit-learn, PyTorch, Optuna, SHAP.

## Установка и запуск

### Настройка окружения

1.  Установите зависимости:
    ```bash
    uv sync
    ```

2.  Сгенерируйте gRPC файлы из proto-определений:
    ```bash
    make proto
    ```

### Запуск

Запустите сервис с помощью `uv`:
```bash
uv run python -m app.grpc_server
```

## Использование Docker

Сборка образа:
```bash
make docker-build
```

## Разработка

-   `make proto` — генерация gRPC кода.
-   `make proto-clean` — очистка сгенерированных файлов.
-   `notebooks/` — директория с Jupyter ноутбуками для экспериментов и анализа данных.
